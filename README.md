# 📱 Mobile Sales Dashboard | Power BI

## 📌 Project Overview

The **Mobile Sales Dashboard** is an interactive Business Intelligence project developed using Microsoft Power BI to analyze mobile phone sales performance and generate meaningful business insights.

This project provides a comprehensive analysis of sales, quantity sold, transactions, average price, brand performance, mobile models, customer ratings, payment methods, and geographical sales distribution.

The dashboard consists of three interactive report pages: Main Dashboard, Month-to-Date (MTD) Report, and Same Period Last Year Report.

## 🎯 Project Objectives

- Analyze overall mobile sales performance.
- Monitor key business performance indicators (KPIs).
- Identify top-performing mobile brands and models.
- Understand city-wise sales distribution.
- Analyze customer preferences and payment methods.
- Evaluate monthly, quarterly, and daily sales trends.
- Compare current sales performance with the same period of the previous year.
- Generate actionable insights to support business decision-making.

## 📊 Dashboard Features

### 1. Main Dashboard

Provides an overview of mobile sales performance through interactive KPIs, charts, and visualizations.

**Key Performance Indicators (KPIs):**
- Total Sales
- Total Quantity
- Total Transactions
- Average Price

**Visualizations:**
- Total Sales by City using geographical maps.
- Total Quantity by Month.
- Ratings by Rating Status (Good, Average, Poor).
- Transactions by Payment Method.
- Total Sales by Mobile Model.
- Total Sales by Day Name.
- Brand-wise Sales and Transaction Summary.

**Interactive Filters:**
- Mobile Model
- Payment Method
- Brand
- Month

### 2. Month-to-Date (MTD) Report

Provides a detailed view of mobile sales performance using Month-to-Date analysis.

**Key Features:**
- Monitors Total Sales, Total Quantity, Transactions, and Average Price.
- Analyzes sales performance by Year, Quarter, Month, and Day.
- Tracks daily and monthly sales trends.
- Provides interactive month-wise filtering.
- Helps monitor sales performance over selected time periods.

### 3. Same Period Last Year Report

Compares current-year sales performance with the corresponding period of the previous year.

**Key Features:**
- Compares Total Sales with Same Period Last Year.
- Analyzes year-wise sales performance.
- Provides quarterly sales comparisons.
- Visualizes month-wise sales trends.
- Displays a comparison table containing Year, Quarter, Total Sales, and Same Period Last Year.

## 💡 Key Business Insights

The dashboard helps businesses understand:

- Which mobile brands and models generate higher sales.
- Which cities contribute significantly to overall sales.
- How customers prefer to make payments.
- How customer ratings are distributed.
- How sales quantities change across different months.
- How current sales performance compares with the previous year.
- Which days and periods show different sales patterns.

## 🚀 How to Use This Project

1. Clone or download this GitHub repository.
2. Open the downloaded project folder.
3. Navigate to the `Dashboard` folder.
4. Open `mobile.pbix` using Microsoft Power BI Desktop.
5. If required, update the dataset source using the Excel file available in the `Dataset` folder.
6. Explore the dashboard using interactive filters and slicers.
